# 🌳 B+ 树可视化 —— 一条数据在数据库索引里的一生

一个美观且交互式的 B+ 树 / 数据库索引可视化工具,帮助理解 B+ 树如何存储和检索数据。
单文件 Streamlit 应用,结构与 [cnn_visualizer](https://github.com/fumolan/cnn_visualizer) 对标。

![Python](https://img.shields.io/badge/Python-3.9+-blue) ![Streamlit](https://img.shields.io/badge/Streamlit-1.30+-red)

## ✨ 主要特性

### 🔄 真实的 B+ 树引擎(纯 Python 实现)
- **插入**:定位 → 写入 → 页满分裂 → 分隔键上浮 → 根分裂树长高
- **删除**:定位 → 删除 → 借键 / 合并 → 根收缩树降高
- **查找**:主键查询 1 次树查找;二级索引查询演示完整"回表"流程
- **范围查询**:定位起点后沿叶子链表顺序扫描
- 阶数可调(3~6),支持随机填充、重置

### 👀 双树对照,索引与数据分得清清楚楚
- **聚簇索引(主键树)**:叶子页 = 整行数据(数据本体)
- **二级索引(name 树)**:叶子页 = `name → 主键`(目录卡)
- 按 name 查询时演示:先查目录卡拿到主键 → **回表**再查聚簇索引取整行

### 🎬 每个操作拆成可回放的步骤
- 每步带叙述文字 + SVG 高亮:🔵 路径/命中、🟢 新写入、🟠 分裂/上浮
- 上一步 / 下一步 / 自动播放
- 悬浮任意数据格子可看完整行内容

### 🎨 精美的 UI
- 渐变标题栏、现代卡片设计
- 统计卡片(行数 / 叶子页数 / 树高 / 阶数)
- 原理速览面板

## 🎯 使用指南

1. **理解"索引 ≠ 数据"**:看两棵树的叶子页——左边挂整行,右边只有 `name→主键`
2. **观察页分裂**:连续插入几行(如 8、9、10…),叶子页满 → 一分为二 → 键上浮,橙色高亮
3. **理解回表**:选「🔍 查找 → 按 name」,跟着 4 步走完"查目录 → 回表 → 取整行"
4. **观察删除平衡**:删到某页只剩 1 个键,看它向兄弟借键或与兄弟合并
5. **范围扫描**:「📏 范围查询」看蓝色虚线链表如何被顺序扫描
6. **调节阶数**:阶数越小树越高、页越少;阶数越大树越矮、页越满 —— 这就是数据库页大小的权衡

## 📐 核心原理速览

- **索引 ≠ 数据**:整行数据只存在聚簇索引(主键树)的叶子页;二级索引只存 `索引键 → 主键`
- **查找 = 树下降**:内部节点只放路标键,每层一次比较,O(log n) 直达叶子
- **分裂**:叶子页满 → 一分为二,分隔键**复制**上浮;根分裂则树长高,所有叶子永远同层
- **借键/合并**:删除后低于下限就向兄弟借,兄弟不够就合并,连锁可能导致树降高
- **回表**:二级索引只拿到主键,必须回聚簇索引再查一次才能取出整行
- **对应 InnoDB**:这里的"页"≈ InnoDB 的 16KB 页;真实引擎还有 Buffer Pool 与 redo log(WAL)

## 📝 注意事项

- 二级索引键(name)要求唯一,方便演示;真实数据库的二级索引允许重复(内部会拼接主键)
- 删除采用标准 B+ 树再平衡(借键/合并);InnoDB 实际实现用"延迟合并 + 闲时清理"策略
- 每个浏览器会话独享一棵树,互不影响
